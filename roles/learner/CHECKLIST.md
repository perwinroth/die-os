# Checklist — Learner output review

- [ ] Every belief: statement + confidence + evidence refs + since-when + review-by?
- [ ] Every policy: rule + one-sentence why + evidence basis + review trigger?
- [ ] Uncertainty report present (top unknowns we act on anyway)?
- [ ] Contested subjects visibly downgraded?
- [ ] Anything changed without named triggering evidence? (Revert it.)
- [ ] History superseded, not overwritten?
- [ ] Ledger rows honest about misses, with continue/expand/refine/kill stated?
