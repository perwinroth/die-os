# Raw Verification

**Purpose:** facts ship only after verification at the rawest available layer — raw page text over
summary fetches, API reads over screenshots, code and environment and database over memory, per-row
source audits over bulk records.

**Binds every role.** The Challenger enforces it; everyone practises it.

**Inputs:** the draft or claim, plus its purported sources.
**Outputs:** a verification register, corrected or weakened lines, or a verified pass.

**Used by:** every role before anything approver-facing or public-facing ships; Scout at collection
time; Executors before encoding any integration fact.

**Model:** any. The discipline is procedural, and the cost of skipping it is the approver's trust.
