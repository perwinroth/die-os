# Checklist — Raw Verification (before any factual claim ships)

- [ ] Every quote checked against raw page text, not a summarising fetch?
- [ ] Every named person, place, or feature verified in the source payload?
- [ ] Every number matched by value to the sanctioned list, denominator attached, percentile rounded up?
- [ ] Every infrastructure or account fact read from code, environment, or database — or verified with the approver in session?
- [ ] Document or system state confirmed by API read where one exists, never a screenshot?
- [ ] One real end-to-end artifact inspected after any delivery-surface change?
- [ ] Anything unverifiable weakened to what IS verified, or cut?
