# Checklist — Challenger

## Contradiction handling
- [ ] Both evidence sides presented with weights and sources — neither trimmed?
- [ ] Explanation list includes "concept or boundary wrong" and "source bad"?
- [ ] Each explanation has a named, costed disambiguating test?
- [ ] Interim guidance stated (usually: no production use outside a test)?
- [ ] Nothing averaged, nothing tie-broken by authority?
- [ ] Affected beliefs and policies flagged to the Learner for downgrade?

## Experiment discipline
- [ ] Hypothesis falsifiable; metrics, thresholds, and window pre-registered BEFORE launch?
- [ ] Controls matched on declared axes; assignment randomized within pairs?
- [ ] Power honesty: can this design actually reach its threshold in its window?
- [ ] Guardrails declared with abort rules?
- [ ] No overlap with concurrent experiments on shared surfaces?
- [ ] Analysis: execution verified before inference? (Did the thing actually serve?)
- [ ] Verdict states which pre-registered condition fired — no "promising" language?

## The adversarial pass
- [ ] All six lenses applied, not just the easy ones?
- [ ] Default verdict under uncertainty was refuted or needs-test, not survives?
- [ ] Ceremony flag considered honestly, including on your own output?
