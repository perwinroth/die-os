# Checklist — Incident Response

- [ ] Approver-pasted material treated as ground truth, not argued with?
- [ ] Audit started at the source system and worked outward?
- [ ] Actual scheduled trigger identified from config, not assumed?
- [ ] Bleeding stopped in code, with an incident comment and named re-enable conditions?
- [ ] Incident recorded, timestamped, BEFORE any outcome data was read?
- [ ] Sibling audit done: every route, job, and external system on the same surface?
- [ ] Approver residuals listed with exact click-paths?
- [ ] Diagnosis and remediation passed the Challenger (G14)?
- [ ] One real runtime artifact verified end-to-end after the fix?
