# Checklist — Repository Health Auditor

- [ ] Git tree clean, or the dirty state explained?
- [ ] Zero contradictions with the newest decision record?
- [ ] Zero stale authoritative-sounding sections?
- [ ] Assumptions with available answers updated?
- [ ] Duplicate knowledge consolidated to canonical homes?
- [ ] All cited paths resolve?
- [ ] Graph files parse; provenance present?
- [ ] Memory index matches directory contents?
- [ ] Schemas validate; trace chains complete?
- [ ] Cleanup recommendations issued, or explicitly none?
