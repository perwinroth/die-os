# Checklist — Synthesis output review

## INTERPRET lane
- [ ] Every hypothesis falsifiable in one sentence, with a named kill-test?
- [ ] Every interpretation cites the specific observations or outcomes it rests on?
- [ ] Alternative explanations listed, each with what would exclude it?
- [ ] Anything claimed beyond the data? (Delete it.)
- [ ] Surprises flagged rather than explained away?
- [ ] Proposed experiments ranked by value-of-information per approver-hour?
- [ ] At least two genuinely distinguishable achievement hypotheses (G12)?

## CURATE lane
- [ ] Every new or changed edge: source, evidence refs, confidence, n, last_updated?
- [ ] All confidence values arithmetic, none judged?
- [ ] Conflicts recorded both-sided and flagged contested — nothing averaged, nothing deleted?
- [ ] Only the declared relationship types used?
- [ ] Supersession used instead of deletion, everywhere?
- [ ] Any duplicate or overloaded concepts flagged with evidence?

## PRESENT lane
- [ ] Every claim cites a specific truth field, query, or graph edge (G1)?
- [ ] Objective-property claims backed by deterministic truth evidence (G2)?
- [ ] No dead concepts; contested items only inside their test, and flagged?
- [ ] Rollback note present per item (G6)?
- [ ] Reads as itself, not as generic optimized copy?
- [ ] Length and format limits respected?
- [ ] Confidence equals the graph's confidence — not a fresh estimate?
- [ ] Predicted outcome and reason filled honestly? (Calibration depends on it.)
