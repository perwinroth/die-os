# The Council — five seats, one verdict

The Challenger is the STANDING adversarial role. The Council convenes only for decisions where
**being wrong is expensive and the right answer is genuinely non-obvious**: positioning, pricing,
pivots, launches.

Not for factual queries, code review, or anything a single Challenger pass covers.

## Protocol — four stages, one session

1. **FRAME.** Neutrally restate the decision and the real constraints from repository context —
   laws, budgets, prior rulings. One paragraph, no advocacy. Show it before proceeding.
2. **FIVE SEATS deliberate in parallel** (as subagents where available, otherwise sequentially with
   strict persona separation). Each answers WITHOUT hedging:
   - **CONTRARIAN:** why this fails; the strongest case against.
   - **FIRST-PRINCIPLES:** which assumptions are load-bearing and unverified.
   - **EXPANSIONIST:** the biggest honest upside if pushed further.
   - **OUTSIDER:** the naive customer's or reader's view; what the jargon hides.
   - **EXECUTOR:** what it costs to actually do; the Tuesday-morning reality.
3. **PEER REVIEW.** Each seat critiques the other four **anonymized** (labelled A–E), naming one
   blind spot and one point conceded.
4. **CHAIRMAN SYNTHESIS.** One verdict: points of agreement, live conflicts (never papered over),
   and a recommendation with its confidence stated. **If the seats split 3-2 or worse, the verdict
   SAYS SO** and frames the approver's choice instead of faking consensus.

## House rules — these bind every seat

- Project laws apply inside the council. No fabricated facts or numbers; cite repository documents
  and measurements where they exist; honesty outranks kindness.
- **The approver receives the SYNTHESIS, not five transcripts.** The full transcript is committed
  for the record.
- A council verdict never overrides an approver ruling or a pre-registration. It can recommend
  reopening one, explicitly.
- A cross-model variant, with guest seats on different model families, is allowed for the
  highest-stakes calls when the approver asks. State the cost first.

## Output

A dated transcript file: frame, five positions compressed, peer-review highlights, verdict. Linked
from the decision record it serves.
