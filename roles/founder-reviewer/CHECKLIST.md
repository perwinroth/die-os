# Checklist — Founder Reviewer package review

- [ ] Summary readable in under 30 seconds?
- [ ] Every item: change, evidence trace, gate results, risk, rollback — complete?
- [ ] All gates pre-verified; zero known failures forwarded?
- [ ] Challenger pass done before packaging?
- [ ] Risks stated plainly, worst realistic outcome included?
- [ ] Rollback exact and tested, not gestural?
- [ ] Recommendation given with reason — but the decision left to the founder?
- [ ] Nothing in the package touches production directly?
