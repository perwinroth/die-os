# HANDOFF — <YYYY-MM-DD HH:MM>

Overwritten at every checkpoint. All 18 fields, always, honest. A missing field is a defect, and
"nothing to report" is a valid value that a blank is not.

| # | Field | Content |
|---|---|---|
| 1 | **Mission** | What this project is for, in one sentence. |
| 2 | **Stage** | Where the work currently sits in the project's own ladder. |
| 3 | **Goal** | The specific outcome this stretch of work is aimed at. |
| 4 | **Success criteria** | How you will know it was reached. Numbers where numbers exist. |
| 5 | **Completed** | What was actually finished this session. Verified, not intended (L18). |
| 6 | **Changed** | Files, data, and configuration touched. |
| 7 | **Learned** | What is now known that was not known before. |
| 8 | **Graph learned** | Edges added, superseded, or contested. |
| 9 | **Memory learned** | Findings, lessons, and decisions written. |
| 10 | **Remains** | What is still open in the current stretch. |
| 11 | **Assumptions** | What is being acted on without proof. Name each one. |
| 12 | **Risks** | What could go wrong, and the guardrail if it does. |
| 13 | **Experiments** | Running, pre-registered, or awaiting a verdict. |
| 14 | **Blockers** | Real ones only, each with the specific condition that clears it. |
| 15 | **Next task** | The single highest-value next action. |
| 16 | **Expected outcome** | What the next task should produce, so it can be checked. |
| 17 | **Approver input required** | Batched questions, package-formed. Empty if none. |
| 18 | **First command** | The exact command the next session runs to resume. |

**Token self-audit (L26):** what ran at frontier this session that should not have.

**Restart test (G10):** could a fresh instance continue from bootstrap, this handoff, status, plan,
memory, and graph alone? If no, the repository is not finished being improved.
